# 会议数字人 设计文档

日期：2026-11-11

## 目标

一个跑在本机 Mac 上的数字人，像同事一样参加会议：听得懂多人讨论，主动接话、提问、反驳、总结，
能现场联网查资料、读代码、调用本地 Claude 做设计，并把结果讲出来、显示出来。

支持两种场景，共用同一套流水线：

| | 当面开会 | 线上会议（腾讯会议 / 飞书） |
|---|---|---|
| 听 | 电脑麦克风或会议全向麦 | 虚拟声卡 BlackHole 收会议软件的声音 |
| 说 | 电脑扬声器或会议室音箱 | 虚拟麦克风送进会议 |
| 形象 | 屏幕、电视或投影 | OBS 虚拟摄像头送进会议 |

## 已确认的决定

- 入会方式：本机虚拟参会人，不依赖任何会议平台的机器人接口。
- 形象：本地实时渲染的动态形象，不做仿真人脸。
- 发言方式：积极参与讨论。点名必答；有实质内容时主动开口；别人一说话立刻让话。
- 大脑：只用本机已登录的 `claude` 命令行，不需要任何密钥。
- 语音识别、断句、声纹全部本地运行；语音合成用 edge-tts。

## 实测依据

- `claude -p` 冷启动首字约 15 秒，不可用于对话。
- `claude -p --input-format stream-json` 常驻进程，第二轮起首字约 0.5 秒。
- 所以快脑必须常驻并在开会前预热。

## 架构

```
浏览器「形象页」(收音 + 播放 + 动画)
   │  16k 单声道 PCM ↑        ↓ 语音片段 + 状态事件
后端 (FastAPI)
   ├─ ears    断句(silero VAD) → 识别(SenseVoice) → 声纹归属
   ├─ meeting 会议状态：字幕、说话人、任务、数字人状态
   ├─ floor   发言决策：何时触发快脑、何时让话、何时放弃
   ├─ fast    快脑：常驻 Claude Haiku，决定说什么或保持安静
   ├─ slow    慢脑：按需启动本地 Claude Code，查资料 / 读代码 / 做设计
   ├─ mouth   按句合成语音
   └─ api     REST + WebSocket，每个操作一个接口
浏览器「控制台」(字幕、说话人改名、任务、开关)
```

收音和播放都放在形象页里，原因：浏览器自带回声消除，当面开会时数字人不会把自己的声音当成别人说话；
线上会议时只需在页面里把输入输出设备换成虚拟声卡。

### 两层大脑

- **快脑**：每听完一句话收到新增字幕，输出三选一：`[静]`（不说话）、要说的话、要说的话加一条派工指令
  `[[派工 类型:简述]]`。输出边生成边按句送去合成。
- **慢脑**：收到派工后在后台启动一个本地 Claude Code 进程。类型三种：
  - `查资料`：只开 WebSearch、WebFetch。
  - `查代码`：只读工具，工作目录为控制台里登记的项目目录。
  - `做设计`：可写 `workspace/designs/` 下的文件，产出 HTML。
  结果全文显示在形象页的资料板上，摘要回灌给快脑，由它在停顿处口头汇报。

### 发言决策规则

1. 有人在说话时绝不开口；要说的话先举手等待，出现 0.4 秒以上的空档再说。
2. 举手期间又有人说了新的话，放弃这次发言，带着新内容重新判断。
3. 说话过程中检测到别人持续说话超过 0.3 秒，立刻停下，并告诉快脑自己说到哪里被打断。
4. 会场连续安静 6 秒，提示快脑一次，由它决定是否总结或推进。
5. 控制台可一键「闭嘴」（停下当前发言）和「静音」（只听不说）。

### 说话人区分

每段语音提取声纹，与已知说话人做余弦相似度比较，超过阈值归入，否则新建「说话人 N」。
控制台可改名，改名后快脑收到的字幕带真名。过短的片段沿用上一位说话人。

## 接口（供界面、测试和 AI Agent 共用）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/state` | 会议全量状态 |
| POST | `/api/meeting/start` `/api/meeting/stop` | 开始、结束会议（启动、关闭快脑） |
| POST | `/api/utterance` | 以文字注入一句与会者发言（测试和 Agent 用） |
| POST | `/api/say` | 让数字人直接说一句话 |
| POST | `/api/hush` | 停下当前发言 |
| POST | `/api/mute` | 静音开关 |
| PATCH | `/api/speakers/{id}` | 说话人改名 |
| POST | `/api/tasks` | 直接派一个后台任务 |
| PATCH | `/api/settings` | 名字、嗓音、场景、项目目录 |
| WS | `/ws/events` | 状态事件流 |
| WS | `/ws/audio` | 形象页音频通道：上行 PCM，下行语音片段 |

## 错误处理

- 快脑进程退出：自动重启并把最近字幕重新喂入；控制台显示「大脑重连中」。
- 语音合成失败：退回系统自带语音。
- 后台任务超时（默认 5 分钟）或失败：标红显示，并让快脑口头说明没查到。
- 界面上只显示人话，不显示网址和原始报错。

## 测试

- 单元测试：分句、快脑输出解析、发言决策状态机、声纹归属。
- 端到端：用合成语音文件模拟与会者，经 `/ws/audio` 送入，验证字幕、回应、让话。
- 界面：浅色、深色、窄屏各看一遍。

## 分期

1. 当面开会：耳朵、快脑、发言决策、嘴、形象、控制台。
2. 干活能力：慢脑三类任务和资料板。
3. 线上会议：设备切换、虚拟声卡和虚拟摄像头的接入说明、实测。

## 不做

- 仿真人脸口型同步。
- 多人同时说话的语音分离。
- 会议平台的机器人接口、云端部署、多会议并发。
